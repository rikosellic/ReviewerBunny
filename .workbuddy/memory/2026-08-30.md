## 基于《高级心理统计 刘红云》整理方法与易错点参考

- PDF 在 `C:\Users\66419\Desktop\调试统计\【教材】高级心理统计 刘红云.pdf`（74MB 扫描版，434 页，纯图片无文字层）。
- 提取流程：发现 PDF 无文字层（pymupdf 抽取为空，每页一张图）→用 pymupdf 渲染关键页为 PNG →用 Read 工具视觉读取（印刷页=PDF页-14）。
- 提取范围：前言 + 目录（14 章）+ 各章"一些值得注意的问题"段落（Ch1 §3-4 数据准备/缺失/异常/假设；Ch3 §7-8 多元回归；Ch4 §4 Logistic；Ch6 §5 聚类；Ch7 §6 EFA；Ch8 §4-5 CFA；Ch9 §7 路径；Ch10 §5-6 SEM；Ch11 §5 中介；Ch12 §3-6 调节/有调节的中介/有中介的调节；Ch13 §4 多层中心化；Ch14 §3 追踪研究）。
- 产出文件：`references/statistics-from-liu-hongyun.md`——按"方法 → 易错点 → 通用写作建议"组织；引文标注原始页码；可被 ReviewerBunny skill 在审稿时按需加载。
- 教材核心观点（已沉淀到参考文档）：①方法选择由"能回答什么研究问题"决定；②数据清理与假设检验是基础；③效应量+置信区间+显著性检验三者并重；④中介分析需关注"总效应不显著的中介"和"遮掩效应"；⑤SEM/CFA 需关注样本量-自由参数比和协方差矩阵使用规范；⑥多层线性模型中心化方式影响截距解释；⑦调节效应需先中心化再构造交互项。
- 可重用流程沉淀：扫描版教材/参考书的关键内容提取 = pymupdf 渲染 + 视觉读取；后续遇到类似场景（图片型 PDF 教辅、规范手册）可直接复用。
