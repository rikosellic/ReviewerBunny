If the analysis involves a continuous variable and a potentially continuous but dichotomously measured variable, the Point-Biserial Correlation Coefficient should be applied. If the analysis involves two dichotomous variables, the Phi Coefficient or chi-square tests should be used to examine group differences. If the analysis involves rank variables, Spearman's correlation coefficients should be used.
